## 📋 Overview

This repository contains the source code for my **Virtual CV (Portfolio Website)** built as part of Deliverable 1 for Profile Development. 

The website serves as a dynamic, interactive digital curriculum vitae showcasing my technical proficiency in **Software Development (C#, Java)**, **Relational Databases (SQL Server, Oracle)**, **Computer Networking (Cisco Packet Tracer)**, and **Web Engineering**.

---

## ✨ Features & Technical Highlights

- 🌙 **Persistent Dark / Light Theme Toggle**: State saved across user sessions using `localStorage`.
- 💻 **Interactive Developer CLI Terminal**: Built-in simulated command terminal in the hero section supporting commands like `help`, `about`, `skills`, `projects`, `contact`, and `clear`.
- 🏷️ **Categorized Skill Grid**: Interactive tab filtering (`All`, `Languages`, `Web Tech`, `Databases`, `Networking & Tools`) with visual progress indicators.
- 🚀 **Filterable Projects Grid & Detail Modals**: Projects filterable by category with interactive popups providing deep-dive technical specs.
- 🎓 **Interactive Resume & Education Timeline**: Detailed academic background at North-West University and project milestones.
- 📋 **Click-to-Copy & Contact Form**: One-click email copying with toast notification alerts and validated message form.
- 📱 **100% Fully Responsive Layout**: Custom CSS Grid and Flexbox implementation compatible with desktop, tablet, and mobile browsers.

## 🚀 Local Development Setup

To run this project locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Kaaskrulle01/virtual-cv.git
   ```

2. **Navigate into the project directory:**
   ```bash
   cd virtual-cv
   ```

3. **Launch the app:**
   Open `index.html` directly in any standard web browser (Chrome, Firefox, Edge, Safari), or serve using VS Code Live Server / `npx serve`.

---

## 🌐 GitHub Pages Deployment Guide

To deploy this Virtual CV to GitHub Pages:

1. Push your repository commits to GitHub:
   ```bash
   git add .
   git commit -m "Enhance Virtual CV portfolio design and interactivity"
   git push origin main
   ```
2. On GitHub, navigate to your repository **Settings** > **Pages**.
3. Under **Build and deployment** > **Branch**, select `main` and folder `/ (root)`.
4. Click **Save**. The website will be published automatically at `https://Kaaskrulle01.github.io/virtual-cv/`.

# 🌐 Virtual CV Portfolio

A modern, responsive personal portfolio website built to showcase my skills, projects and experience as a final-year Information Technology student.

The website serves as my online CV, allowing recruiters and employers to learn more about my technical skills, academic projects, and professional profile.

---

## 📖 Overview

This portfolio was developed using HTML, CSS and JavaScript with a focus on clean design, responsiveness and usability.

Features include:

- Responsive layout for desktop and mobile
- Light/Dark mode toggle
- Interactive navigation with active section highlighting
- Skills section with category tabs
- Project showcase
- Resume timeline
- Contact section
- Back-to-top button
- Smooth scrolling throughout the website
